# Hello, My Name Is AI

> What's in a name? That which we call a model
> By any other name would hallucinate as much.

**[everyainame.com](https://everyainame.com)**

An incomplete catalog of every **named** AI we could find: the assistants, chatbots and agents that companies, governments and universities gave a name, from Bank of America's Erica to Chipotle's Ava Cado. It covers 1,701 AIs from 1,481 organizations. The page lets you browse it as a wall of "HELLO my name is" stickers, with a few charts (name gender by industry, industry share, launches over time).

A silly project by [Lukas Thoms](https://electriclantern.co). Don't take it too seriously.

## How it was made

The research was done by Claude agents running in Claude Code, in rounds: big brands and banks first, then governments, universities, credit unions and other sectors, then systematic passes over the Fortune 1000, the Y Combinator directory and AI startup lists (Forbes AI 50, CB Insights AI 100, VC portfolios and agent directories). Altogether that took 4,654 web searches.

The rules every entry had to meet:

- **A distinct name.** "AI Assistant" or "Company AI" doesn't count; Erica, Bixby and Joule do.
- **Live now, or announced in 2024-2026.** Retired AIs were dropped, renamed ones carry their current name.
- **A source someone actually opened.** Every entry links to a page that confirms the AI and its name. Agents weren't allowed to add anything from memory.

Launch dates came from a separate pass: a script fetched every source page for date hints, then agents confirmed each date against a press release or news story, with the evidence recorded in `data/launch_dates/`.

The worklists, agent prompts and helper scripts used during research aren't in this repo; it holds only what the build needs.

## Caveats

- **It's incomplete.** New named AIs launch every week, and some sectors were searched much harder than others (banks, governments, universities, the Fortune 1000 and AI startups), so the industry counts reflect where we looked as much as where companies name their AIs.
- **Only live AIs are listed,** so earlier years look quieter on the launch chart than they were.
- **Gender and funniness are judgement calls.** Gender is how the name usually reads as a first name, not what the company intended.
- **Mistakes are likely** in a list this size. Corrections are welcome.

## Corrections and additions

Open an issue, or send a pull request that edits the relevant file:

- A wrong or missing AI: add or fix it in a `research/round*/` file, with a source URL.
- A wrong gender, funny score or launch date: edit the file in `data/`.

Then run `python3 scripts/build.py` and commit the regenerated `ai_names.csv` and `site/` files.

## What's in the repo

```
ai_names.csv         The dataset: one row per named AI (generated by the build)
src/
  template.html      The page: layout, styles and all the browsing code
  og.html            Source for the social preview image (command to regenerate is inside)
site/                What gets deployed to everyainame.com
  index.html         The built page: every card pre-rendered, plus search and social tags (generated)
  ai_names.csv       A copy of the dataset for download (generated)
  robots.txt, sitemap.xml (generated), favicon.svg, og.png
data/                Hand-curated inputs merged in by the build
  name_gender.json     "name|company" -> feminine / masculine / neutral
  name_funny.json      "name|company" -> 1-3 (missing = 0)
  editors_picks.json   Ordered list of "name|company" shown first by default
  list_labels.json     Fortune 1000 / Y Combinator tags for companies from rounds 1-3
  launch_dates/        Launch month research, one file per batch of entries
research/
  round1 ... round5/   Raw findings from each research round (JSON, one file per agent)
  audit_round3.json    Fixes from an audit pass: retired AIs, renames, better sources
scripts/
  build.py             Merges research + data into ai_names.csv and the site/ folder
```

## Build it

Python 3, no dependencies:

```sh
python3 scripts/build.py
open site/index.html
```

## Deploy

The `site/` folder is a static site, hosted on Cloudflare Pages:

```sh
npx wrangler pages deploy site --project-name everyainame
```

The build prints anything that needs a look: duplicates it dropped, names that more than one company uses (to confirm they're different AIs), and new entries missing a gender.

## The dataset

`ai_names.csv` has one row per AI:

| Column | Meaning |
|---|---|
| `name` | The AI's name, as the company styles it |
| `company` | Who runs it (a company, government body, university, etc.) |
| `project` | The product or channel it lives in, when that helps |
| `use` | One or two sentences on what it does |
| `category` | One of 18 broad industries |
| `nameType` | `human` if it's a person's first name, otherwise `brand` |
| `source` | A page that confirms the AI and its name |
| `list` | Fortune 1000 rank, Y Combinator batch, and/or "AI-native startup" (joined with " · ") |
| `gender` | How the name reads: `feminine`, `masculine` or `neutral` (brand and unisex names are neutral) |
| `funny` | 0-3, a judgement call |
| `pick` | Position in the Editor's Picks (blank for most rows) |
| `launched` | Launch month (`YYYY-MM`), or year (`YYYY`) when that's all we could find |
| `launchBasis` | `launched`, `announced` (no go-live date found) or `earliest mention` (it existed by then) |
